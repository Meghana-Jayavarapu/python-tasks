## How to Run
Open the project in VS Code and run each `.py` file with Python.
For Web Scraper:

```bash
cd Intermediate/01_Web_Scraper
pip install -r requirements.txt
python scraper.py
```

For Hangman:

```bash
cd Intermediate/02_Hangman
python hangman.py
```
